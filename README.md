# Facebook Clone App

A Facebook-inspired mobile application built using React Native and Expo.

## Features

- Login Screen
- Home Feed
- Stories Section
- Like Functionality
- Search Screen
- Recent Searches
- Profile Screen
- Logout Feature
- Mini To-Do List
- Bottom Tab Navigation

## Technologies Used

- React Native
- Expo
- React Navigation
- JavaScript
- Lucide React Native Icons

## Installation

```bash
git clone https://github.com/AimaJahangir/FacebookClone2.git
cd FacebookClone2
npm install
npx expo start
```
